# Everworld sports lab

Test lab and working copies for two live apps:

- **Courtside Arcade** (NBA player projections): https://everworldlife-courtside-arcade.static.hf.space
- **GG Winner** (H2H GG League and real-league totals): https://everworldlife-gg-winner.static.hf.space

Start with [`NOTES.md`](NOTES.md): what has been measured, what failed, and the exact commands.

This folder is separate from the Pace Totals app in the repo root (it is excluded from that app's Docker image).
