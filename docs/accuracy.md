## What the backtest changed

| Finding | Fix |
|---|---|
| Team totals ran ~5 pts low | Offensive rebounds create extra shots: shot volume now uses plays per possession (FGA + 0.44 FTA + TOV ÷ possessions) |
| Rotation players not dressing still got minutes | Each team's minutes are trimmed/filled to exactly 5 × time left |
| "85%" rungs hit 79% | Wider minutes uncertainty (`minShock` 0.24): calibration error 0.0006 → 0.0002 |
| DataBallr's injury feed can miss outs (Jaylen Brown, 10/31) | A 20+ mpg player who missed his team's last game is presumed out pregame; one-tap Playing/Out overrides; "Check X" button |
| 80/20 season/tonight blend vs 70/30, 65/35 | No measurable difference — kept 80/20 |
