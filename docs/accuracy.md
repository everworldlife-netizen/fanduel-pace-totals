## Post-mortem: 2026-10-31 (`npm run postmortem -- 2026-10-31 q1`)

Seven games, five decided by 18+. What went wrong and what changed:

| Problem | Evidence | Fix |
|---|---|---|
| Back-to-back rest not detected | PHI (Embiid, LeBron), MIN (Gobert), HOU (VanVleet) all sat on night two; DataBallr's injury report didn't list them, so teammates were under-projected | Back-to-back detection; 31+ year-old starters flagged "back-to-back rest risk"; pregame picks for unconfirmed players are hidden until confirmed |
| Injury feed gaps | Morant (out 4+ weeks per Shams) not in DataBallr's report | Questionable / Doubtful statuses now used (Doubtful = out); flags + Check X |
| "Missed last game" over-excluded | Jaylen Brown (38 min), Sengun (33), Markkanen (29) returned | Kept the 20+ mpg rule (backtest still favors it) but players are flagged so you can confirm |
| Starters who never checked in still projected live | After Q1, Embiid / LeBron still projected ~25 min | Live: a 24+ mpg player not in by minute 10 (or 14+ mpg by minute 18) is out; minutes and shots go to teammates |
| Blowouts badly underestimated | Model said 6% (pregame) / 13% (after Q1) chance of a 20+ lead into Q4; it happened in 25% of games | Margin path recalibrated (team-strength drift ×2, live swing 2.8/√min, pregame sd 16) → predicted 24–25% |
| Remaining points ran high (+4 per team) | Pace counted OT games per game, not per 48; 4th quarters run ~6% fewer possessions; early-season makes ~2.5% below last season | Pace per 48 minutes, `q4Pace` 0.94, `shotEff` 0.975 → team bias +3.6 → +0.4 |

Last night at the end of Q1: points MAE 4.81 → 4.44, minutes MAE 6.02 → 5.42. Across all 32 games every checkpoint improved (Q3 points 2.31 → 2.25, team score MAE 8.60 → 8.05).

Tested and **not** adopted (no gain): a stronger 80/20 → 70/30 tonight blend, a "close-game closers" minutes floor, presuming back-to-back veterans out by default.
